# Complete AI Engineering TR

A Turkish-first, open-source curriculum that teaches AI engineering from Python and mathematics to production-grade LLM, RAG and agentic systems.

## Language policy

- Course explanations: Turkish
- Technical terminology: Turkish with English equivalents
- Code, identifiers and repository structure: English
- International documentation: progressively translated into English

## Scope

The curriculum covers Python, computer science, mathematics, data engineering, classical machine learning, deep learning, computer vision, NLP, Transformers, LLM engineering, retrieval-augmented generation, parameter-efficient fine-tuning, agentic AI, MCP, MLOps/LLMOps, evaluation, security and responsible AI.

See the [Turkish guide](README.tr.md), [curriculum](CURRICULUM.md) and [contribution guide](CONTRIBUTING.md).
