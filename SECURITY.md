# Güvenlik Politikası

## Güvenlik açığı bildirme

Güvenlik açıklarını herkese açık issue olarak yayımlamayın. GitHub özel güvenlik bildirimi etkinse onu kullanın; değilse maintainer'lara özel kanaldan ulaşın.

Bildirimde şunları paylaşın:

- Etkilenen dosya veya bileşen
- Yeniden üretme adımları
- Beklenen ve gerçekleşen davranış
- Olası etki
- Varsa güvenli çözüm önerisi

## Eğitim kodu uyarısı

Depodaki bazı kodlar öğrenme amacıyla sadeleştirilmiş olabilir. Bir örneği üretimde kullanmadan önce kimlik doğrulama, yetkilendirme, giriş doğrulama, secret yönetimi, rate limiting, logging ve tehdit modellemesi uygulayın.

## Yasaklanan içerikler

- API anahtarları ve parolalar
- Gerçek kişilere ait hassas veriler
- İzinsiz özel veri setleri
- Zararlı veya yetkisiz erişimi kolaylaştıran uygulamalar
