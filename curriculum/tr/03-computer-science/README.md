# Modül 3 — Bilgisayar Bilimleri ve Yazılım Mühendisliği

Bu modül; algoritmik düşünme, veri yapıları, karmaşıklık analizi, temiz kod, test, debugging ve temel sistem bilgisini AI mühendisliği bağlamında öğretir.

**Modül durumu:** Tamamlandı

## Tamamlanan dersler

1. [Algoritmik Düşünme, Big-O ve Temel Veri Yapıları](01-algorithms-big-o-data-structures/README.md) — karmaşıklık analizi, array/list, stack, queue, hash table ve linked list
2. [Arama, Sıralama ve Recursion](02-search-sort-recursion/README.md) — linear ve binary search, temel sıralamalar, merge sort, quick sort, recursion ve benchmark tasarımı
3. [Tree, Heap ve Graph](03-tree-heap-graph/README.md) — BST traversal, priority queue, adjacency list, BFS, DFS, topological sort ve cycle detection
4. [Test, Debugging, Profiling ve Logging](04-testing-debugging-profiling-logging/README.md) — pytest, fixture, parametrization, dependency injection, hata ayıklama, cProfile ve güvenli logging
5. [Linux, Process, Thread, HTTP ve REST Temelleri](05-linux-process-thread-http-rest/README.md) — Linux çalışma ortamı, subprocess, concurrency, thread safety, HTTP sözleşmeleri ve inference API tasarımı

## Modül kazanımları

Bu modülü tamamlayan öğrenci:

- Algoritma ve veri yapısı seçimlerini karmaşıklık açısından değerlendirebilir.
- Arama, sıralama, tree, heap ve graph algoritmalarını uygulayabilir.
- Test, debugging, profiling ve logging araçlarıyla sorun teşhis edebilir.
- Linux process yaşam döngüsünü ve kontrollü concurrency yaklaşımını açıklayabilir.
- HTTP/REST tabanlı, test edilebilir küçük bir AI servisi tasarlayabilir.

Her ders; teori, İngilizce kod örnekleri, alıştırmalar, quiz, ödev, mülakat soruları, testler ve metadata ile yayımlanır.
