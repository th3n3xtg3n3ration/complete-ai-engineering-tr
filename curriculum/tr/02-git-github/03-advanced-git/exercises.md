# Alıştırmalar

1. `git log --graph --oneline --all` çıktısındaki branch ve merge noktalarını yorumla.
2. Son dört commit'i interactive rebase ile yeniden adlandır.
3. İki düzeltme commit'ini `fixup` ile ana commit'e birleştir.
4. Commit sırasını değiştirmenin oluşturabileceği riski açıkla.
5. Başka bir branch'ten tek commit cherry-pick et.
6. Cherry-pick conflict oluştur ve çöz.
7. `git cherry-pick --abort` kullanarak işlemi geri al.
8. Yanlışlıkla `reset --hard` uygula ve reflog ile commit'i kurtar.
9. Kurtarılan commit için ayrı bir recovery branch'i aç.
10. `--soft`, `--mixed` ve `--hard` reset sonuçlarını karşılaştır.
11. Sekiz commit içeren bir regresyon senaryosunda manuel bisect yap.
12. Aynı bisect sürecini bir test betiğiyle otomatikleştir.
13. `--force` ve `--force-with-lease` farkını ekip senaryosuyla açıkla.
14. Paylaşılan branch'te rebase yerine revert seçilmesi gereken bir örnek yaz.
15. Model ağırlıklarının neden normal Git geçmişine konmaması gerektiğini açıkla.
