# Ders 1 — Git Temelleri ve Güvenli Çalışma Akışı

**Seviye:** L1 · **Tahmini süre:** 8 saat · **Durum:** Tamamlandı

## Öğrenme hedefleri

Bu dersin sonunda:

- Git repository, working tree, staging area ve commit kavramlarını açıklayabileceksin.
- Küçük ve anlamlı commit'ler oluşturabileceksin.
- Branch açıp değişiklikleri merge edebileceksin.
- Merge conflict çözebileceksin.
- Remote repository ile güvenli biçimde çalışabileceksin.
- `restore`, `revert` ve kontrollü `reset` arasındaki farkları açıklayabileceksin.
- `.gitignore` ve secret yönetimi için temel güvenlik kurallarını uygulayabileceksin.

## Mini proje

Bir makine öğrenmesi deneyi için branch tabanlı çalışma akışı kuracak; veri, kod ve dokümantasyon değişikliklerini ayrı commit'lerle yönetecek; kasıtlı bir merge conflict'i çözecek ve repository hijyenini otomatik olarak kontrol edeceksin.
