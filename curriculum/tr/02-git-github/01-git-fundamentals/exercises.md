# Alıştırmalar

1. Yeni bir repository oluştur ve ilk commit'i yap.
2. `git status`, `git diff` ve `git diff --staged` çıktıları arasındaki farkı gözlemle.
3. Yalnızca seçili satırları stage etmek için `git add -p` kullan.
4. Üç farklı amaç için üç ayrı commit oluştur.
5. Bir feature branch aç ve merge et.
6. Kasıtlı merge conflict üret ve çöz.
7. Yanlışlıkla stage edilen bir dosyayı stage alanından çıkar.
8. Çalışma alanındaki tek bir dosyanın değişikliğini geri al.
9. Paylaşılmış kabul edilen bir commit'i `revert` ile tersine çevir.
10. `.gitignore` dosyasına Python ve notebook girdileri ekle.
11. `git log --graph --oneline --all` çıktısını yorumla.
12. Bir remote ekle ve `fetch` ile uzak referansları indir.
13. `pull --ff-only` başarısız olabilecek bir senaryoyu açıkla.
14. Büyük model dosyalarının neden normal Git geçmişine konmaması gerektiğini yaz.
15. Bir secret commit edildiğinde izlenecek acil müdahale adımlarını sırala.
