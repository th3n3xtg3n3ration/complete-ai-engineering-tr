# Alıştırmalar

1. Bir bug için bağlam, tekrar adımları ve kabul kriterleri içeren issue yaz.
2. Üç farklı görev için Conventional Commit uyumlu branch adı üret.
3. 20 dosyalık bir değişikliği incelenebilir üç PR'a böl.
4. Kapsamı belirsiz bir PR açıklamasını yeniden yaz.
5. Blocking, suggestion, question ve nit türlerinde birer review yorumu yaz.
6. Merge commit, squash merge ve rebase merge için uygun senaryolar belirle.
7. `main` branch'i için önerilen protection kurallarını listele.
8. Model, API ve güvenlik dizinleri için CODEOWNERS tasarla.
9. Bir review yorumuna savunmacı olmayan teknik yanıt yaz.
10. Bir PR'a sonradan eklenen commit sonrası hangi onayların yeniden alınması gerektiğini açıkla.
11. `P0`, `P1`, `bug`, `feature` ve `documentation` label sistemi tasarla.
12. Bir minor release için changelog girdisi hazırla.
13. Yanlışlıkla yayınlanan API anahtarı için olay müdahale adımlarını yaz.
14. Fork'tan gelen bir PR'ın GitHub Actions izinlerini güvenlik açısından değerlendir.
15. Issue'dan release'e kadar tüm akışı küçük bir örnek repository üzerinde uygula.
