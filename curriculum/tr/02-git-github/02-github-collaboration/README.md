# Ders 2 — GitHub İş Birliği, Pull Request ve Code Review

**Seviye:** L1 · **Tahmini süre:** 10 saat · **Durum:** Tamamlandı

## Öğrenme hedefleri

Bu dersin sonunda:

- GitHub Flow ile güvenli bir iş birliği süreci kurabileceksin.
- Issue, branch ve pull request ilişkisini açıklayabileceksin.
- İncelenebilir ve küçük pull request'ler hazırlayabileceksin.
- Yapıcı code review yorumu yazabileceksin.
- Merge, squash merge ve rebase merge stratejilerini karşılaştırabileceksin.
- Branch protection, CODEOWNERS ve zorunlu kontrolleri yapılandırabileceksin.
- Release, tag ve changelog akışını uygulayabileceksin.
