# Ödev — Issue'dan Release'e GitHub Akışı

## Görev

Küçük bir AI API repository'sinde aşağıdaki uçtan uca iş akışını uygula:

1. Problem ve kabul kriterleri bulunan bir issue aç.
2. Issue ile ilişkili feature branch oluştur.
3. Kod, test ve dokümantasyon değişikliklerini anlamlı commit'lere ayır.
4. Pull request şablonunu kullanarak draft PR aç.
5. En az iki self-review notu ekle.
6. Bir review geri bildirimini yeni commit ile çöz.
7. Uygun merge stratejisini gerekçelendir.
8. `main` için branch protection taslağı hazırla.
9. CODEOWNERS dosyası oluştur.
10. Semantic Versioning'e uygun tag ve release notu hazırla.

## Teslimler

- Issue bağlantısı veya ekran görüntüsü
- Pull request bağlantısı
- Commit geçmişi
- Review konuşmaları
- Branch protection açıklaması
- CODEOWNERS
- Release notu
- Kısa retrospektif

## Rubrik — 100 puan

- Issue kalitesi ve kabul kriterleri: 10
- Branch ve commit disiplini: 15
- PR kapsamı ve açıklaması: 15
- Test/doğrulama kanıtı: 15
- Review kalitesi ve geri bildirim işleme: 15
- Branch protection ve CODEOWNERS: 10
- Merge stratejisi gerekçesi: 5
- Release ve versioning: 10
- Güvenlik ve repository hijyeni: 5

## Başarı ölçütü

En az 70 puan. Secret, kişisel erişim anahtarı veya gerçek üretim kimlik bilgisi commit edilmesi ödevin başarısız sayılmasına neden olur.
