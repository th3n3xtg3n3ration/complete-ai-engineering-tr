# Modül 1 — Python

Bu modül, yapay zekâ mühendisliğinde kullanılacak programlama temelini kurar.

## Tamamlanan dersler

1. [Python Temelleri](01-python-fundamentals/README.md) — değişkenler, veri tipleri, kontrol akışı, fonksiyonlar ve testler
2. [İleri Python](02-python-advanced/README.md) — generator, decorator, context manager, typing, dataclass ve özel exception tasarımı
3. [Nesne Yönelimli Programlama ve Tasarım İlkeleri](03-oop-design/README.md) — composition, polymorphism, SOLID, protocol ve dependency injection
4. [Dosya, Paket ve Bağımlılık Yönetimi](04-files-packages-dependencies/README.md) — pathlib, JSON, atomik yazma, pyproject.toml, sanal ortam ve test izolasyonu
5. [Asenkron Python ve Eşzamanlılık](05-async-python-concurrency/README.md) — asyncio, task, gather, timeout, retry, semaphore, queue ve cancellation
