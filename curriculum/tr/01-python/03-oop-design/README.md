## Öğrenme hedefleri

Bu dersin sonunda:

- Sınıf, nesne, özellik ve metot kavramlarını açıklayabileceksin.
- Encapsulation, inheritance, composition ve polymorphism yaklaşımlarını karşılaştırabileceksin.
- `dataclass`, abstract base class ve protocol kullanabileceksin.
- SOLID ilkelerini küçük Python tasarımlarına uygulayabileceksin.
- Test edilebilir, genişletilebilir bir alan modeli geliştirebileceksin.
