# Ödev — Güvenilir Ensemble Model Sistemi

Bir kredi riski veya churn veri setinde altı modeli karşılaştır:

- Decision Tree
- Random Forest
- AdaBoost
- Gradient Boosting
- Soft Voting
- Stacking

## Zorunlu teslimatlar

1. Leakage-safe split
2. Baseline
3. Pruning deneyi
4. OOB değerlendirme
5. En az üç cross-validation metriği
6. Generalization gap
7. Impurity ve permutation importance
8. Segment bazlı hata analizi
9. Test seti nihai değerlendirmesi
10. En az 20 otomatik test
