# Laboratuvar — Ölçeklenmiş ve Kalibre Edilmiş SVM

1. Karışık tipte binary classification verisi üret.
2. Train/validation/test split oluştur.
3. Linear ve RBF SVM karşılaştır.
4. Scaling etkisini göster.
5. `C` ve `gamma` için grid search uygula.
6. `class_weight="balanced"` deneyini yürüt.
7. ROC-AUC, average precision, F1 ve balanced accuracy raporla.
8. Support vector oranını ölç.
9. Sigmoid ve isotonic calibration karşılaştır.
10. Validation üzerinde threshold seçip testte tek sefer uygula.
