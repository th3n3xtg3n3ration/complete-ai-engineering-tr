# Ödev — Güvenilir Kernel SVM Sistemi

Bir üretim hattında kusurlu ürünleri tespit eden leakage-safe SVM sistemi geliştir. Linear ve RBF SVM, `C`/`gamma` araması, scaling, class weight, calibration, threshold ve segment analizi içermelidir.

Gereksiz manuel inceleme maliyeti **₺25**, kusurlu ürünü kaçırmanın beklenen maliyeti **₺400** olarak kullanılacaktır.
