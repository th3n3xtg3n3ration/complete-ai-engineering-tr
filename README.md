## Hızlı başlangıç

```bash
git clone <REPOSITORY_URL>
cd complete-ai-engineering-tr
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
python -m pip install -r requirements-dev.txt
pytest
```

İlk ders: [`curriculum/tr/00-orientation/01-ai-ecosystem`](curriculum/tr/00-orientation/01-ai-ecosystem/README.md)

## Temel ilkeler

1. **Türkçe anlatım, uluslararası kod standartları**
2. **Sezgi → matematik → sıfırdan kod → framework → gerçek proje**
3. **Her derste ölçülebilir öğrenme çıktıları**
4. **Test edilen kod ve doğrulanan içerik**
5. **Sıfırdan üretime kadar kesintisiz öğrenme yolu**
6. **Güvenlik, etik ve değerlendirme baştan itibaren müfredatın parçasıdır**
