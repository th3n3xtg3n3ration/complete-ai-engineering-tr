# Teknik Sözlük

| Türkçe | İngilizce | Kısa tanım |
|---|---|---|
| Yapay zekâ | Artificial intelligence | İnsan benzeri algılama, karar veya üretim görevlerini gerçekleştiren sistemler alanı |
| Makine öğrenmesi | Machine learning | Kuralları tek tek yazmak yerine veriden örüntü öğrenen yöntemler |
| Derin öğrenme | Deep learning | Çok katmanlı sinir ağlarına dayanan makine öğrenmesi yaklaşımı |
| Büyük dil modeli | Large language model | Büyük metin koleksiyonları üzerinde token dizilerini modelleyen sinir ağı |
| Gömme | Embedding | Nesneleri anlam ilişkilerini taşıyan sayısal vektörlerle temsil etme |
| Çıkarım | Inference | Eğitilmiş modelin yeni girdi için çıktı üretmesi |
| İnce ayar | Fine-tuning | Önceden eğitilmiş modeli belirli görev veya alana uyarlama |
| Bilgi getirimi destekli üretim | Retrieval-augmented generation | Üretim öncesi ilgili dış bilgiyi getirip modele bağlam verme |
| Ajan | Agent | Hedefe ulaşmak için durum izleyen, karar veren ve araç kullanan sistem |
| Değerlendirme | Evaluation | Sistem kalitesini ölçülebilir testlerle inceleme süreci |
