# Sık Sorulan Sorular

## Matematik bilmeden başlayabilir miyim?

Evet. Matematik modülü temel fonksiyonlardan başlar ve kodla birlikte ilerler.

## Güçlü ekran kartı gerekli mi?

Başlangıçta hayır. İleri modüllerde küçük modeller, quantization, Colab ve bulut seçenekleri kullanılır.

## Eğitim yalnızca notebook'lardan mı oluşacak?

Hayır. Notebook, test edilebilir Python paketi, API ve gerçek uygulama birlikte kullanılacaktır.

## İçerik tamamen Türkçe mi?

Anlatım Türkçedir. Teknik terimler İngilizce karşılıklarıyla, kod isimleri ise İngilizce öğretilir.

## Sertifika verilecek mi?

İlk sürümlerde resmî sertifika yoktur. Ölçülebilir proje ve değerlendirme çıktıları portföy kanıtı olarak tasarlanır.
